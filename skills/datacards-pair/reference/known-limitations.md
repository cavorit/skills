# Known Limitations

Temporary workarounds for weaknesses of the platform. Read this before the
first draft of a deck.

Rules for this file:

- Only workarounds for things the platform is expected to fix. Lasting
  knowledge belongs in the other reference files.
- Every entry names its issue and the date it was added, so it can be deleted
  when the issue is closed.

Entry format:

```
## <building block or function>: <what goes wrong>
Added: YYYY-MM-DD · Issue: ENG-…
Workaround: …
```
